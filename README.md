# BKShot——不坑截图&录屏标注软件

截图、标注、局部放大、录 GIF、录屏、屏幕演示、文字识别与截图翻译。

[下载安装包 · 1.4.16](https://github.com/44886/BKShot/releases/download/v1.4.16/BKShot-1.4.16-win-x64-Setup.exe) · [便携版](https://github.com/44886/BKShot/releases/latest/download/BKShot-win-x64-Portable.zip) · [微软应用商店](https://apps.microsoft.com/store/detail/XP8LNLSW2085Z8) · [更新记录](https://github.com/44886/BKShot/releases)

当前发行版支持 Windows 10 / Windows 11 x64。商店版本随审核进度更新。

## ✅ 快捷截图

- 快捷键或托盘启动，框选后原位标注、复制、保存、贴图或进入高级编辑。
- 悬停选取窗口和可识别控件，滚轮切换层级，也可自由框选。
- 框选后继续拖动四边、四角或整个选区，调整范围和位置。
- 在选区外的遮罩区域点击右键即可取消截图。
- 指针旁显示像素放大镜、坐标和颜色，支持高分辨率、系统缩放与多显示器。

## ✅ 标注与手写

| 工具 | 功能 |
| --- | --- |
| 矩形、椭圆、正圆 | 框出重点，设置边线颜色、粗细、线型及矩形圆角 |
| 自由画笔 | 自由圈画、移动、缩放和旋转 |
| 手写笔 | 平滑笔迹、粗细变化与起收笔锋，适合批注和演示书写 |
| 荧光笔 | 自由涂画或拖选矩形，半透明高亮突出重点 |
| 箭头 | 经典线、渐粗、实心粗、空心、双向和折线六种样式 |
| 文字 | 直接输入，选择字体、字号、颜色、描边和旋转角度 |
| 步骤编号与说明 | 编号搭配文字，制作操作步骤图 |
| 马赛克 | 遮挡敏感内容，调整像素块大小 |
| 聚光高亮 | 压暗背景，突出一个或多个区域 |

- 快速编辑与高级编辑均可连续添加；点击已有标注即可修改。
- 直接拖动控制点调整尺寸、旋转、箭头端点、曲度和转折位置。
- 支持实线、虚线、点线和点划线；旋转时按 Shift 可按 15° 对齐。
- 自由画笔和荧光笔按住 Shift 可画水平、垂直直线。
- 文字框随内容增长，拖动四角调整字号；`Enter` 完成，`Ctrl+Enter` 换行。
- 支持撤销、重做，记住各工具的颜色、粗细、字体、样式和下拉选项。
- 悬停任意滑块可用滚轮调节；字号等数字框聚焦后也支持滚轮调值。

## ✅ 配套说明图风格

- 内置清晰说明、手绘笔记、醒目贴纸、技术文档、红白种草、气泡贴纸、奶油手账、荧光重点、毛笔批注、蓝白教程、撞色漫画 **11 套风格**。
- 文字、编号与箭头呈现配套效果。
- 可使用内置字体，也可搜索选择本机字体。

## ✅ 局部放大镜

- 框出小字、按钮或图片细节，在旁边放大展示。
- 展开式、悬浮卡片、镜片三种外观，清晰／平滑两种画质。
- 来源区域与放大区域独立移动、缩放，设置边线、圆角和连接效果。

## ✅ 屏幕标注与演示

- 无需截图，直接在桌面绘制图形、箭头、文字、步骤和笔迹，可配合录屏使用。
- 支持自由画笔、手写笔、荧光笔、橡皮、清空、撤销和重做。
- 切换鼠标穿透，保留标注并继续操作下面的窗口。
- 演示聚光灯跟随鼠标，柔和突出指针周围，可调整范围和外围暗度。
- 多种鼠标指针预设，支持自定义 PNG、大小和点击热点。
- 托盘或快捷键开启；工具条记住拖动位置，显示器变化后调整到可见区域。

## ✅ GIF 与视频录制

- 框选区域录制，支持独立快捷键，也可从截图工具条进入。
- 选区旁的工具条设置参数，录制时显示范围，支持暂停、继续和结束。
- 录制期间可切换窗口、操作任务栏。
- **GIF**：设置帧率、输出宽度和时长上限。
- **MP4 视频**：设置画质、15 / 30 FPS、是否录入鼠标光标。
- 声音可选静音、系统声音、麦克风或混合录音。
- H.264 与 HEVC（H.265）可选，支持设备上可录制原尺寸 5K 区域。
- 记住录制参数，结束后按保存设置输出。

## ✅ 纵向与横向长截图

- 框选后向下或向右滚动，截取长网页、文章和横向宽表格。
- 实时预览，支持暂停、继续、结束与回滚补采。
- 改善局部动态图片、动画内容下的长截图体验。
- 完成后继续标注、裁切和保存。

## ✅ OCR 文字识别

- 识别截图文字，结果可校对、修改和复制。
- 整理阅读顺序与段落，改善多栏内容的文本输出。
- Windows x64 可选增强识别，提升中文小字识别效果，下载组件后可离线使用。

## ✅ 截图翻译

- 支持百度、有道、阿里云、腾讯云翻译，填写自己的服务密钥。
- 可选源语言与目标语言，支持自动识别源语言。
- 图片与双语文本对照，支持修改原文、校正译文和复制结果。
- 可切换原位译文，复制或保存翻译后的图片。

## ✅ 高级编辑与多图排版

- 添加截图或本地图片，移动、缩放、旋转、裁切，设置图片圆角、边线与阴影。
- 一键设置常用画布比例，调整宽高，拖动四边和角点改变画布范围。
- 图层显示／隐藏、锁定、置顶／置底，多选、全选、复制粘贴、生成副本。
- 导入多张图片，调整顺序后拼接。
- 保存可编辑项目，之后继续修改。
- 新截图或长截图按图片尺寸建立新画布。

## ✅ 置顶贴图、取色与二维码

- 截图原位置顶贴图，淡阴影区分屏幕内容，方便对照查看。
- 拖动移动、滚轮缩放，`Ctrl+滚轮` 调整透明度；右键复制、保存或关闭。
- 支持快捷键贴出截图或剪贴板图片。
- 选区前即可拾取屏幕颜色，`C` 复制并退出，`Shift` 切换 HEX / RGB。
- 快速编辑支持取色和标注颜色吸管。
- 识别截图中的二维码，支持多个结果和内容复制。

## ✅ 水印、圆角与输出

- 图内水印：Logo、标题、副标题，调整位置、字号、颜色和透明度。
- 图外底栏：Logo、标题、时间、图片尺寸、分隔线与背景。
- 保存水印模板，快速编辑与高级编辑均可调整并沿用上次选择。
- 最终图片支持四周圆角、边线颜色与线型、阴影颜色、浓度、柔化和偏移。
- PNG / JPEG、50%–400% 输出倍率、JPEG 质量与 DPI 设置。
- PNG 支持透明圆角与阴影外围。
- 可每次询问保存位置，或直接保存到指定目录；询问时沿用上次目录。

## ✅ 快捷键、历史与更新

- 自定义截图、OCR、取色、贴图、GIF、录屏、屏幕标注快捷键。
- 按键录入，支持 F1、PrintScreen 等单键及组合键，检查重复与占用。
- 开机启动、托盘驻留、首次使用教程。
- 可选截图历史：预览、复制、贴图、编辑、另存、删除、清空和保留数量设置。
- 检查新版、国内下载通道、GitHub 下载页及微软商店入口，支持下载进度、取消和重试。
