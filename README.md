# BKShot

**截图与标注软件，由不坑老师制作。**

常驻托盘，快捷键截图，框选后直接标注、打码、识字、取色和复制。用统一风格的文字、步骤与箭头，把截图做成清楚、漂亮的说明图。基础功能无需登录；GIF、滚动长截图、水印及装饰风格需微信登录后使用。

## 开始使用

1. 启动 BKShot 后，软件常驻右下角系统托盘。首次正常启动会打开「设置 → 教程」，显示当前快捷键，并可点击「立即截图」。托盘图标可能藏在右下角“^”展开的隐藏图标中。
2. 按截图快捷键，拖动框选区域；也可悬停窗口或可识别的控件并单击选取。
3. 框选后直接使用浮动工具条标注。拖动边缘、四角可再次调整范围；选择模式下拖动空白处可移动选区。
4. 完成后复制、保存、贴图，或送到高级编辑器继续整理。

绿色的「复制截图」按钮位于工具条最右侧。复制保持原始尺寸与无损像素，大图的剪贴板编码在后台完成。

首次教程只显示一次，升级保留已展示状态；开机启动保持后台驻留。以后可在「设置 → 教程」再次查看。关闭教程后仍在后台运行。

关闭编辑器后仍保持托盘常驻；完全退出请使用托盘菜单中的「退出 BKShot」。

开机启动默认关闭。在「设置 → 常规」中勾选「登录系统后自动启动 BKShot」并保存，下次登录系统时自动驻留托盘；取消勾选并保存即可关闭。启动项使用固定启动器，自动更新后继续有效。便携版启用后请保持目录位置，移动目录后重新保存设置。

本版安装包注册卸载时的启动项清理规则。仅从旧安装版原位更新的用户，卸载前请先关闭开机启动，或运行本版安装包覆盖安装。

## 快捷键

以下是默认快捷键，可在设置中点击快捷键录制框，按下新组合后保存。被其他软件占用的组合需要更换。

| 操作 | 快捷键 |
| --- | --- |
| 截图 | `Ctrl+Shift+A` |
| 文字识别 | `Ctrl+Shift+O` |
| 屏幕取色 | `Ctrl+Shift+P` |
| 框选后复制图片 | `Enter` / `Ctrl+C` |
| 框选后保存 | `Ctrl+S` |
| 框选后识字 | `O` |
| 框选后复制指针处颜色 | `C` |
| 切换颜色格式 | 按一下 `Shift`，切换 HEX / RGB |
| 取消截图 | `Esc` |

文字输入期间，`Enter` 完成、`Shift+Enter` 换行、`Esc` 取消本次文字修改；取色快捷键不会打断文字输入。

## 标注与说明图

- **框与箭头**：加框按钮右侧下拉选择矩形、椭圆或正圆；正圆绘制和调整时保持比例，矩形圆角可调。支持颜色、粗细、实线、虚线、点线、点划线；箭头可选直线或弯曲，拖动控制点自由调整曲度。
- **文字与步骤**：直接在截图上输入，双击重新编辑；字号可调，拖动四角缩放文字，步骤编号与说明同步缩放。
- **马赛克与聚光**：遮挡隐私内容，或压暗周围画面突出重点；支持多个聚光区域、独立调整聚光圆角，或恢复跟随风格。
- **配套风格**：十一套标注风格：清晰说明、手绘笔记、醒目贴纸、技术文档、红白种草、气泡贴纸、奶油手账、荧光重点、毛笔批注、蓝白教程、撞色漫画。配套中文字体、文字描边、配色与步骤编号；各类工具分别记忆上次使用的形状、圆角、颜色、字号、线宽等属性。
- **连续标注**：工具保持选中，持续添加同类元素；切到选择工具可移动和编辑已有标注，支持撤销与重做。
- **多图编辑**：高级编辑器可加入多张图片，管理图层、锁定、显示隐藏、旋转与缩放；保存可编辑的 `.bkshot` 项目（兼容打开旧 `.tuxu`），或导出 PNG/JPEG。

高级编辑器目前采用手动多图排版。

## 其他工具

- **滚动长截图**：框选后点击长截图，在选区内滚动原窗口，停稳后自动拼接；可预览、暂停、继续和完成。页面内容须有足够重叠，复杂动画或布局变化可能影响拼接。
- **本地 OCR**：识别结果可修改、复制；Windows 中文识别需要系统安装对应的 OCR 语言包。
- **取色与放大镜**：显示原始像素、颜色与坐标。框选后的颜色来自冻结的原始屏幕画面。
- **贴图**：截图可置顶贴在屏幕上，调整大小与透明度。
- **GIF 录制**：快速工具条直接显示 GIF 按钮。先框选，再在选区下方的工具条设置参数并录制；区域外压暗、录制边框为红色，显示计时与帧数，支持暂停/继续。点击「结束」后再选择保存位置；取消保存或编码失败时保留已录帧，可重新保存。时长默认上限 30 秒，可调整；另有 600 帧及累计 1.2 亿输出像素的容量限制，到达上限会保留已有动画。静态截图标注不会进入 GIF。
- **可选历史记录**：默认关闭，开启后保存最终截图，可复制、贴图、编辑或删除。
- **水印**：覆盖在图片上，或在图片外添加底部说明栏。支持文字、日期、尺寸、Logo 与模板，快速截图和高级编辑均可使用。

窗口与控件识别使用系统辅助功能接口，无需浏览器插件；未向系统暴露边界的网页元素不能保证被识别。一次普通框选限一块显示器，多块屏幕的截图可在编辑器中合并。

## 微信登录

在「设置 → 账号」或托盘菜单点击登录，直接用微信扫描软件窗口中的二维码，无需浏览器或 WebView2。二维码失效时点击刷新。

基础截图、常规标注、马赛克、聚光高亮、OCR、取色、复制和保存无需登录。GIF、滚动长截图、水印及装饰风格需要有效登录。

BKShot 与不坑盒子共享账号身份，使用独立登录会话，不占用不坑盒子的登录设备额度。退出账号后高级功能停止开放；含水印或特殊风格的项目需要重新登录后输出，或移除相应效果。

登录凭证由 Windows 系统加密保存，恢复时联网验证，运行期间定期检查。短暂网络故障保留有限的验证有效期；长期无法验证时需恢复网络，基础截图仍可使用。

## 更新

在托盘菜单或设置中选择「检查更新」。发现新版后可下载，查看进度、取消或重试，下载校验完成后点击「重启并更新」。请先保存未完成的编辑项目。

安装版和本页提供的完整便携版均支持原位更新。旧测试 ZIP 若提示未配置自动更新，请先安装本页的安装版。

更新文件托管在 GitHub Releases，需要能访问 GitHub 的网络。检查失败时可以重试，或前往下载页手动安装。软件不会在启动截图时进行联网登录或更新检查。

## 图片输出

在「设置 → 图片输出」设置像素倍率（50%–400%）、PNG/JPEG 格式、JPEG 质量及 DPI。DPI 默认为 96，支持 72、96、144、150、300、600 和 36–1200 范围的自定义值。DPI 决定打印与排版时的物理尺寸，不改变像素数量或清晰度；放大像素倍率也不会增加原图细节。剪贴板保持原始像素，并写入所设 DPI。

设置和登录数据从旧目录自动迁移至 `%LocalAppData%/BKShot/data/`，保留原设备标识。
