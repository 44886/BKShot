# BKShot——不坑截图&录屏标注软件

**截图、标注、放大镜、录 GIF、录屏，把屏幕内容做成清楚又好看的说明图。**

BKShot 由不坑老师制作，日常驻留系统托盘。快捷键框选后即可加框、画箭头、写步骤、打码、复制或保存；高级编辑支持多图排版。适合软件教程、操作演示、问题反馈、文档配图与内容创作。

当前发行版本支持 Windows 10 / Windows 11 x64。商店版本随审核进度更新。

## ✅ 快捷截图与精准选区

- 快捷键或托盘启动截图，框选后在原位直接编辑。
- 悬停选取窗口和可识别控件，滚轮切换选取层级，也可自由拖动框选。
- 框选后继续拖动四边、四角调整范围，或移动整个选区。
- 指针附近显示像素放大镜、坐标与颜色，方便精确取边。
- 适配高分辨率屏幕、系统缩放与多显示器。
- 快速复制、保存、贴图，或转入高级编辑。

## ✅ 丰富的标注工具

快速截图和高级编辑均可使用，工具保持选中，支持连续添加。

| 工具 | 功能 |
| --- | --- |
| 矩形、椭圆、正圆 | 框出重点，调整颜色、粗细、线型和矩形圆角 |
| 自由画笔 | 手绘线条、圈画重点，支持移动、缩放和旋转 |
| 荧光笔 | 半透明涂画突出重点，保持原文可读 |
| 箭头 | 六种样式，支持曲度、转折位置、端点及旋转调整 |
| 文字 | 直接在图片上输入，自由选择字体、字号、颜色和角度 |
| 步骤编号与说明 | 编号搭配说明文字，制作清楚的操作步骤图 |
| 马赛克 | 遮挡敏感区域，调整像素块大小 |
| 聚光高亮 | 压暗背景，突出一个或多个重点区域 |
| 局部放大镜 | 框出细节，在旁边放大展示，独立调整两处区域 |

- 支持实线、虚线、点线和点划线，在适用的工具中调整。
- 点击已有标注直接修改，拖动控制点调整大小、方向或曲度。
- 支持旋转柄，按 Shift 可按 15° 对齐角度。
- 自由画笔与荧光笔按住 Shift 可画水平或垂直直线。
- 支持撤销、重做；高级编辑还支持多选及对象复制粘贴。
- 颜色、粗细、字体、字号、下拉工具和样式等沿用上次选择。

## ✅ 六种箭头样式

- **经典线箭头**：简洁指示按钮、字段和操作方向。
- **渐粗箭头**：一端细、一端粗，突出指向与重点。
- **实心粗箭头**：醒目指示，适合重点说明。
- **空心箭头**：强调轮廓，搭配不同图片风格。
- **双向箭头**：展示对应关系、距离与两端联系。
- **折线箭头**：转折指向，方便避开重要内容。

下拉菜单提供轮廓预览。可修改已有箭头的样式；曲线箭头可拖动控制点调整弯曲，折线箭头可调整转折位置。起点、终点和旋转均可直接在画面上调整。

## ✅ 局部放大镜

突出小字、按钮、字段及图片细节，让说明图更容易看懂。

- **展开式、悬浮卡片、镜片**三种外观。
- 来源区域与放大区域都能独立拖动、缩放和调整。
- 支持边线颜色、粗细、线型、圆角及连接强度等设置。
- 区域重叠时自动隐藏连接，减少遮挡。
- **清晰／平滑**两种画质可选，默认清晰，沿用上次选择。
- 高倍放大受原图清晰度限制，按内容选择合适倍率。

## ✅ 统一的说明图风格

内置 **11 套标注风格**：清晰说明、手绘笔记、醒目贴纸、技术文档、红白种草、气泡贴纸、奶油手账、荧光重点、毛笔批注、蓝白教程、撞色漫画。文字、步骤编号和箭头呈现配套效果。

- 字体可跟随风格，也可搜索选择本机字体。
- 可选站酷快乐体、站酷庆科黄油体、马善政毛笔等内置字体。
- 文本输入框随内容增长，拖动四角快速调整字号。
- `Enter` 完成输入，`Ctrl+Enter` 强制换行，双击文字继续修改。
- 其他标注不显示干扰查看的虚线编辑框，保留缩放与旋转操作。

## ✅ 高级编辑与多图排版

- 添加截图或本地图片，移动、缩放、旋转，搭配标注制作完整说明图。
- 一键设置 1:1、4:3、3:4、16:9、9:16、3:2、2:3 或自由画布比例。
- 设置画布宽高、锁定比例，直接拖动四边和角点调整画布范围。
- 图片裁切、圆角、边线与阴影，保留需要的内容并整理外观。
- 图层显示／隐藏、锁定、置顶／置底，管理图片与标注顺序。
- `Ctrl+A` 全选可见且未锁定对象，Shift 点击增减选择。
- 多选后整体移动、复制粘贴、生成副本或删除。
- 导入多张图片，调整顺序后拼接。
- 保存 `.bkshot` 可编辑项目，之后继续修改；兼容打开旧 `.tuxu` 项目。
- 关闭编辑窗口结束本次编辑，下次新截图或长截图按图片尺寸建立新画布。

## ✅ 区域录 GIF

框选录制范围，在选区旁的工具条设置参数并开始录制。

- 独立快捷键启动，也可从截图工具条进入。
- 设置时长上限、帧率和输出宽度。
- 录制区域保持提示，支持暂停、继续与结束。
- 录制时可操作其他窗口和任务栏。
- 结束后保存，沿用保存方式设置；取消保存或失败后可重试。

## ✅ 区域录屏

框选区域录制为 MP4，适合操作演示与教程视频。

- 独立快捷键或截图工具条启动录制。
- H.264 兼容模式与 HEVC（H.265）模式可选；支持设备上可录制原尺寸 5K 区域。
- 选择 15 / 30 FPS、不同画质及是否录入鼠标光标。
- 声音可选静音、系统声音、麦克风或两者混合。
- 暂停、继续、结束，录制参数沿用上次选择。
- 录制时可切换窗口、操作任务栏，并随时结束录制。

## ✅ 纵向与横向长截图

- 框选后选择纵向向下或横向向右，在选区内滚动完成长截图。
- 适合长文章、网页内容、横向宽表格等场景。
- 实时预览，支持暂停、继续和结束。
- 遇到拼接提示时，可回滚并小幅滚动补采，保留已采集内容。
- 完成后进入高级编辑，继续标注、裁切和保存。

## ✅ 原位置顶贴图

- 点击图钉，在原截图位置置顶显示，方便对照输入与比较内容。
- 柔和外阴影帮助区分贴图和屏幕内容。
- 拖动移动，滚轮缩放，`Ctrl+滚轮` 调整透明度。
- 右键菜单提供复制、保存、放大、缩小、恢复原始大小和关闭。
- `Esc` 关闭，支持通过快捷键贴出截图或剪贴板图片。

## ✅ OCR、屏幕取色与二维码

- **OCR 文字识别**：识别截图文字，结果可修改和复制。
- **屏幕取色**：选取截图时即可查看颜色，按 `C` 复制并退出截图；按一下 `Shift` 切换 HEX / RGB。快速编辑也可取色，并用吸管设置标注颜色。
- **二维码识别**：识别截图中的二维码，支持多个结果，点击图标复制内容。

## ✅ 水印与说明底栏

- 图内水印：放置标题、副标题与 Logo，调整位置、字号、颜色、对齐和透明度。
- 图外底栏：追加 Logo、标题、截图时间、图片尺寸和分隔线，调整底栏背景。
- 保存命名模板，按场景切换。
- 快速编辑与高级编辑均可调整，沿用上次选择。

## ✅ 圆角、边线、阴影与图片输出

- 为最终图片设置四周圆角，自由调整半径。
- 成图边线支持颜色、粗细与实线／虚线／点线／点划线。
- 成图阴影支持颜色、浓度、柔化与水平／垂直偏移。
- 快速截图、高级编辑与设置共用外观默认值，下次继续沿用。
- 复制、保存、贴图和导出应用最终外观。
- PNG / JPEG、50%–400% 输出倍率、JPEG 质量与 DPI 设置。
- PNG 支持透明圆角和阴影外围；JPEG 使用白色背景。
- 可每次询问保存位置，或直接保存到指定目录；询问时沿用上次目录。
- GIF 与视频同样遵循保存方式设置。

## ✅ 个性化设置、历史与更新

- 分类设置：常规、快捷键、图片输出、水印、账号、教程与关于。
- 勾选开机启动，启动后驻留系统托盘。
- 六项全局快捷键：截图、OCR、取色、贴图、GIF、录屏。
- 点击快捷键输入框直接按键，支持 F1、PrintScreen 等单键及组合键，检查重复与占用。
- 首次启动显示教程，帮助找到托盘入口和常用操作。
- 可选截图历史：预览、复制、贴图、编辑、另存、删除、清空及保留数量设置。
- 检查更新，支持国内下载通道，也可打开 GitHub 下载页或微软商店；支持下载进度、取消和重试。
- 采集期间托盘提供结束并保存、取消的备用入口。

## 常用快捷键

以下为 Windows 默认值，可在设置中修改。

| 操作 | 快捷键 |
| --- | --- |
| 截图 | `Ctrl+Shift+A` |
| OCR | `Ctrl+Shift+O` |
| 屏幕取色 | `Ctrl+Shift+P` |
| 贴图 | `Ctrl+Alt+T` |
| 录 GIF | `Ctrl+Alt+G` |
| 录屏 | `Ctrl+Alt+V` |
| 快速编辑复制图片 | `Enter` / `Ctrl+C`，或双击截图区域 |
| 保存图片 | `Ctrl+S` |
| 文字输入完成 / 强制换行 | `Enter` / `Ctrl+Enter` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` 或 `Ctrl+Shift+Z` |
| 高级编辑全选 | `Ctrl+A` |
| 高级编辑复制 / 粘贴对象 | `Ctrl+C` / `Ctrl+V` |
| 高级编辑生成副本 | `Ctrl+D` |
| 复制指针处颜色 | `C` |
| 切换 HEX / RGB | 按一下 `Shift` |
| 取消当前操作 | `Esc` |

编辑文字时，复制、全选等按键作用于文字。
