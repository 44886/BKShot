# BKShot——不坑截图&录屏标注软件

**截图、标注、放大镜、录 GIF、录屏，把屏幕内容做成清楚又好看的说明图。**

BKShot 由不坑老师制作，日常驻留系统托盘。用快捷键框选后，就能直接加框、画箭头、写步骤、打码、复制或保存；需要多图排版时，再进入高级编辑。适合软件教程、操作演示、问题反馈、文档配图和内容创作。

安装后首次正常启动会打开教程。之后程序驻留右下角系统托盘，也可能位于托盘的隐藏图标中；右键图标可截图、录制、打开高级编辑、设置或退出。

## 快速上手

1. 按 `Ctrl+Shift+A` 截图，拖动框选；也可悬停在窗口或可识别控件上，单击选取。
2. 框选后，拖动四边、四角继续调整范围，在选区上直接添加标注。
3. 点击已有标注即可修改，拖动控制点缩放或旋转；点击空白处继续添加当前工具。
4. 点击工具条最右侧的复制按钮，或按 `Enter` / `Ctrl+C`，复制最终图片。按 `Ctrl+S` 保存，也可贴图或转入高级编辑。

## 截图与精准选区

- **快捷键与托盘截图**：截图后直接在原位编辑，无需先打开独立编辑窗口。
- **窗口与控件吸附**：悬停识别窗口及系统可访问元素，单击选取，滚轮切换层级；按 Alt 或直接拖动可自由框选。控件识别取决于目标应用提供的边界信息。
- **选区二次调整**：框选后仍可拖动边缘、四角或整体位置；调整时保留标注与屏幕内容的对应关系，支持撤销、重做及 Esc 取消当前拖动。
- **指针像素放大镜**：框选时放大鼠标附近的原始屏幕像素，并显示颜色、坐标，方便精确取边。
- **适配高分屏**：按显示器实际像素处理截图，适配屏幕缩放和多显示器；普通框选一次选取一块显示器中的区域。
- **快速输出**：双击截图区域复制含标注的最终图片；双击文字则进入文字编辑。

## 标注工具

快速截图与高级编辑共用标注工具和样式记忆。

| 工具 | 可完成的操作 |
| --- | --- |
| 矩形、椭圆、正圆 | 框出重点，调整颜色、线宽、线型；矩形可调整圆角 |
| 自由画笔 | 手绘线条和圈画重点，调整颜色、粗细、线型，移动、缩放和旋转 |
| 箭头 | 直线、正弯、反弯及不同曲度；拖动曲度控制点自由调整走向 |
| 文字 | 在画面上直接输入，调整字体、字号、颜色和角度；双击重新编辑 |
| 步骤编号与说明 | 添加编号和配套说明，编号与文字一起调整字号，制作操作步骤图 |
| 马赛克 | 遮挡敏感内容，调整区域和像素块大小 |
| 聚光高亮 | 压暗背景、突出一个或多个重点区域，调整压暗强度及区域外观 |
| 局部放大镜 | 框出原图细节，在旁边显示放大内容，独立调整来源区域和放大区域 |

### 统一风格与细节调整

- 内置 **11 套标注风格**：清晰说明、手绘笔记、醒目贴纸、技术文档、红白种草、气泡贴纸、奶油手账、荧光重点、毛笔批注、蓝白教程、撞色漫画。文字、步骤编号和箭头形成配套视觉效果。
- 支持**实线、虚线、点线、点划线**；属性面板随当前对象显示相应设置。
- 文字及步骤可搜索选择本机字体，也可选择站酷快乐体、站酷庆科黄油体、马善政毛笔，或跟随标注风格。输入过程中也能换字体。
- 输入框随文字增长；`Enter` 完成输入，`Ctrl+Enter` 强制换行。拖动文字四角可缩放字号。
- 选中对象后可直接拖动旋转柄；旋转时按 Shift 以 15° 对齐。弯箭头还可独立调整曲度。
- 工具保持选中，可连续添加同类标注。颜色、线宽、线型、字体、字号等按工具记忆；框／画笔、马赛克／聚光灯等下拉选择也沿用上次使用项。

### 局部放大镜

放大镜用于突出按钮、字段、图片细节等小区域，放大内容来自原图。

- 来源框与放大区域都能拖动、缩放和调整。
- 提供 **展开式、悬浮卡片、镜片** 三种外观。
- 支持矩形、椭圆、正圆形状及边线颜色、粗细、圆角等设置；镜片使用正圆。
- 展开式和卡片可调整连接强度；区域重叠时自动隐藏连接，减少遮挡。

## 高级编辑：多图与说明图排版

- **多图画布**：加入截图或本地图片，移动、缩放、旋转，搭配标注整理成完整说明图。
- **画布比例**：一键选择 1:1、4:3、3:4、16:9、9:16、3:2、2:3 或自由比例；支持设置宽高、锁定比例，直接拖动画布四边和角点调整范围。
- **图片裁切**：选中图片后拖动裁切区域，保留需要的内容。
- **图片外观**：设置边线颜色、粗细、线型、圆角，以及阴影颜色、浓度、模糊和偏移。
- **图层管理**：显示／隐藏、锁定、置顶／置底，管理图片和标注的前后关系。
- **多选操作**：`Ctrl+A` 全选可见且未锁定的对象，Shift 点击增减选择；支持整体移动、复制粘贴、生成副本、删除及撤销重做。
- **图片拼接**：导入多张图片，调整顺序后拼接。
- **可编辑项目**：保存为 `.bkshot` 项目，之后继续修改；兼容打开旧 `.tuxu` 项目。
- **独立编辑会话**：关闭高级编辑窗口后结束本次编辑。下次新截图或长截图会按图片尺寸建立新画布；已保存项目和标注样式记忆保留。

## 录 GIF 与区域录屏

### GIF

从快捷工具条或独立快捷键进入，先框选，再在选区下方的工具条设置参数并开始录制。

- 调整时长上限、帧率和输出宽度。
- 录制区域保持边框提示，支持暂停、继续和结束。
- 结束后保存，沿用保存路径设置；保存取消或编码失败时可重试。

### 视频

框选需要的区域，直接在贴边工具条配置并录制为 MP4。

- **H.264 兼容模式**与 **HEVC（H.265）模式**可选；支持设备上可用 HEVC 录制原尺寸 5K 区域，具体编码能力取决于系统和硬件。
- 可选 15 / 30 FPS、不同画质，以及是否录入鼠标光标。
- 声音可选静音、系统声音、麦克风或两者混合。
- 支持暂停、继续、结束，参数沿用上次选择。
- 录制时可操作其他窗口与任务栏，录制工具条保持可操作；GIF 和视频采集会排除自身提示界面。

## 纵向与横向长截图

框选区域，选择纵向向下或横向向右，再在区域内滚动，程序根据相邻画面重叠内容拼接。

- 支持页面长文和横向宽表格等场景。
- 提供实时预览、暂停／继续、结束，并对重复画面去重。
- 针对固定顶栏、底栏、侧栏和细滚动条优化匹配。
- 匹配不可靠时保留已经拼接的结果，按提示回滚并小幅滚动补采。滚动时需保留相邻画面的重叠；重复纹理、大范围动画、冻结窗格等仍可能影响匹配。

## 贴图、OCR、取色与二维码

### 置顶贴图

- 框选后点击图钉，图片在原截图位置置顶，方便对照输入、比较内容。
- 没有常驻工具条，柔和外阴影帮助区分贴图与屏幕内容；阴影不写入复制或保存的图片。
- 拖动移动，滚轮缩放，`Ctrl+滚轮` 调整透明度。
- 右键菜单提供复制、保存、放大、缩小、恢复原始大小和关闭；`Esc` 关闭。
- 贴图快捷键可贴出当前快速编辑结果，或剪贴板中的图片；没有来源位置的图片居中展示。

### 文字识别

使用系统 OCR 识别截图中的文字，结果可修改、复制。Windows 的识别语言取决于已安装的系统 OCR 语言包。

### 屏幕取色

不必先完成框选：选取截图期间即可查看指针位置的颜色，按 `C` 复制颜色并退出本次截图；按一下 `Shift` 在 HEX 与 `rgb(...)` 之间切换。框选后的快速编辑也可继续查看、复制颜色，并用吸管选择标注颜色。

### 二维码识别

自动识别截图区域中的二维码，支持多个二维码。点击浮动图标复制完整内容，不自动打开链接。

## 水印、圆角与图片输出

- **图内水印**：把标题、副标题、Logo 等放在图片角落，调整位置、字号、颜色、对齐和透明度。
- **图外底栏**：在图片下方追加说明底栏，支持 Logo、标题、截图时间、图片尺寸、分隔线及背景色。
- **水印模板**：保存命名模板，按场景切换；快速编辑和高级编辑都可调整水印。
- **自动四周圆角**：在设置、快速编辑或高级画布中控制开关和半径，作用于最终成图外侧四角，包括水印底栏。原始图片资源保留。
- **输出格式与清晰度**：PNG / JPEG、50%–400% 输出倍率、JPEG 质量及 DPI 可设置。DPI 表示打印／排版密度，不会凭空增加图片细节。
- **透明圆角**：PNG 保留透明四角，JPEG 以白色填充透明部分。
- **保存方式**：可每次询问位置，也可直接保存到指定目录；使用保存对话框时沿用上次目录。GIF 和视频同样遵循保存方式设置。

## 设置、历史与更新

- **分类设置**：常规、快捷键、图片输出、水印、账号、教程及关于页面，按用途组织。
- **开机启动**：在设置中勾选，下次进入系统后驻留托盘。
- **六项全局快捷键**：截图、OCR、取色、贴图、GIF 和录屏。点击输入框直接按键，支持 F1、PrintScreen 等单键及修饰键组合；保存时检查重复和占用，系统保留键以实际注册结果为准。
- **可选截图历史**：默认关闭，开启后记录最终截图；可预览、复制、贴图、编辑、另存、删除和清空，并设置保留数量。
- **待机资源回收**：采集结束、贴图和编辑窗口关闭后释放相关图像及渲染资源，日常驻留托盘。
- **检查更新**：托盘与关于页面提供入口，可通过 GitHub 下载更新，也可打开微软商店。GitHub 更新支持下载进度、取消、重试及重启更新。
- **采集中的备用操作**：托盘中的“结束当前录制/长截图并保存”和“取消当前截图、录制或长截图”仅在适用流程中启用，待机时不可用。

## 常用快捷键

以下为 Windows 默认值，可在设置中修改。已有用户的自定义快捷键会保留。

| 操作 | 快捷键 |
| --- | --- |
| 截图 | `Ctrl+Shift+A` |
| 文字识别 | `Ctrl+Shift+O` |
| 屏幕取色 | `Ctrl+Shift+P` |
| 贴图 | `Ctrl+Alt+T` |
| 录 GIF | `Ctrl+Alt+G` |
| 区域录屏 | `Ctrl+Alt+V` |
| 快速编辑中复制最终图片 | `Enter` / `Ctrl+C`，或双击截图区域 |
| 保存图片 | `Ctrl+S` |
| 文字输入完成 / 强制换行 | `Enter` / `Ctrl+Enter` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` 或 `Ctrl+Shift+Z` |
| 高级编辑全选对象 | `Ctrl+A` |

编辑文字时，复制、全选等按键作用于文字；结束输入后再操作标注或截图。

## 静默安装

安装包支持通过参数静默安装，默认安装到 `%LOCALAPPDATA%\BKShot`：

```powershell
.\BKShot-1.3.59-win-x64-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP-
```

可追加 `/DIR="D:\Apps\BKShot"` 指定安装目录，或 `/LOG="安装日志路径"` 保存日志。静默安装不会自动启动软件。
